# 먼저 읽기 — Matths iPad 전체 패키지

이 폴더는 2026-08-11 시점의 Matths iPad 앱 전체 작업본입니다. Xcode 프로젝트, Swift
소스, 앱 에셋, 내장 웹 강의, 랭크 휘장·효과음, 테스트, 로컬 AI용 llama XCFramework를
포함합니다.

1. Claude 또는 새 개발자는 `docs/CLAUDE_인수인계_2026-08-11.md`를 먼저 읽으세요.
2. 프로젝트는 `Matths.xcodeproj`로 엽니다.
3. `build/`, `build-device/`, `build-rank-v2/`, 개인 `xcuserdata`는 전달본에서 제외했습니다.
4. 로컬 AI GGUF 가중치, 로그인 토큰, 인증서·프로비저닝 프로필, DB 비밀정보는 포함하지
   않았습니다.
5. GitHub 원본에는 push·commit하지 않았습니다. 이 패키지는 로컬 작업 스냅샷입니다.

현재 Release를 막는 가장 큰 외부 항목은 정식 서버 도메인과 Apple 서명입니다. Debug
소스 검토와 개발은 가능하지만 임시 터널 주소를 그대로 둔 Release 배포는 금지합니다.
