# 웹 IA 결정 기록 — 60차

## 결과

공개 랜딩과 로그인 후 대시보드의 첫 행동을 GOAT Arena로 바꿨다. 학습·평가·오답·커뮤니티 기능은 제거하지 않고 두 번째 위계와 하위 그룹으로 이동했다.

- 회의 09:41–10:45: 첫 진입에서 아레나를 바로 보이고, 아레나 진입을 1클릭으로 만든다.
- 디자인 원칙 0051·0052·0075·0751·0771·0772: 사용자 목적 중심의 상위 구조, 한눈에 비교 가능한 항목 수, 사이드바 그룹 관계.

## 보존한 계약

- 기존 URL과 기능은 모두 유지했다.
- `/api/v1/*`를 포함한 API 계약은 수정하지 않았다.
- `views/main.ejs`의 섹션별 실패 폴백을 유지하고 테스트 기대값은 사용자 문구의 의도만 갱신했다.
- 아레나 장식 모션은 `transform`·`opacity` 중심이며 `prefers-reduced-motion`에서 정지한다.

## 되돌리기 단위

IA와 아레나 랜딩 변경은 서버 로직과 분리된 EJS/CSS/브라우저 JS 변경이다. 디자인 승인 전에는 push하지 않는다.
